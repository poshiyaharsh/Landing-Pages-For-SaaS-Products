# TestForge — Ship with Confidence

> Enterprise software testing, continuous QA automation, flaky test quarantine, and developer quality tooling.

TestForge is an enterprise QA and developer intelligence landing page and interactive test runner simulation engineered with React 19, TypeScript, Vite, and Tailwind CSS.

## Key Features

- **Interactive Test Suite Runner:** Real-time client-side execution simulation with deterministic timing, step progression, and pass/fail/skipped status metrics.
- **Root-Cause Failure Inspection:** Detailed visual diff between expected and actual assertion values, stack trace analysis, and DOM replay cues.
- **Quarantine Workflow:** One-click flaky test quarantine simulation to prevent pipeline blocking on main branches.
- **Interactive Suite Configuration Modal:** Test runner selector (Playwright, Vitest, Jest, Cypress), target environment, and shard worker sliders.
- **Integration Ecosystem:** Native connectors for GitHub Actions, GitLab CI, Playwright, Vitest, Datadog, Slack, and Linear.
- **Transparent Pricing Model:** Developer, Team, and Engineering tiers with monthly/annual billing toggle.
- **Full Responsiveness & Accessibility:** Optimized for 375px mobile, 768px tablet, and 1440px desktop viewports with zero layout shifts or horizontal overflow.

## Technology Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 6
- **Styling:** Tailwind CSS 3.4
- **Icons:** Lucide React
- **Aesthetic:** Dark terminal / QA developer console with emerald/teal accents and monospace typography.

## Development

```bash
# Install dependencies
npm install

# Start local development server (Port 5204)
npm run dev

# Build for production
npm run build
```

## Disclaimer

TestForge is a simulated SaaS concept for software quality and developer tooling. All demo test runs, failure traces, and execution timings are illustrative client-side fixtures and do not execute actual code against external repositories.
