# DataPulse — Business Analytics

> Your business. Every signal. One place.

A premium futuristic analytics landing page built as an independent React/Vite project.

## Product

DataPulse brings real-time dashboards, KPI monitoring, AI insights, custom reports, and data integrations into one business command center.

## Experience

- Real-time executive dashboard with KPI cards, revenue visualization, acquisition metrics, and live activity stream
- Interactive 7D / 30D / 90D dashboard controls
- AI analyst insight surface
- Data-fabric integrations grid
- Automated executive report builder showcase
- Security-focused positioning
- Responsive pricing and conversion path
- Mobile navigation and demo modal
- Animated charts and orbital data visualization
- prefers-reduced-motion support

## Stack

- React 19
- Vite 6
- JavaScript
- Lucide React
- CSS custom design system
- Space Grotesk, DM Sans, JetBrains Mono

## Run locally

```bash
cd landing-pages/datapulse
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Design direction

DataPulse intentionally avoids a generic admin-dashboard look. The experience uses a black enterprise canvas, mint/violet signal accents, layered glass surfaces, large editorial typography, glowing charts, and restrained motion.
